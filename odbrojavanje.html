Kad se vidimo?

datum se cuva za sve: cim ga sacuvas, vidi ga i Irena

Jos samo jednom

Povezi sajt sa GitHubom da datum vidimo oboje. Ovo radis samo prvi put.

  1. Otvori GitHub → novi token
  2. Token name: za-irenu, Expiration: najduze sto nudi
  3. Repository access: Only select repositories → za-irenu
  4. Permissions → Contents: Read and write
  5. Generate token, kopiraj ga i zalijepi ovdje

Token se cuva zakljucan ovom lozinkom, pa ga vise ne moras unositi ni na jednom telefonu.
